## Kết quả và giới hạn triển khai

Đã viết backend và web cho tạo nháp → publish → ngừng dùng. **Cần phiên tích hợp đăng ký controller và hai provider bên dưới trước khi route mới chạy trong AppModule thật.** Integration dùng Nest module riêng có đủ DI, PostgreSQL `baby_family_test`.

- Mission dùng bảng hiện có: `DRAFT`/rollout 0 → `ACTIVE`/rollout 1–100 → `RETIRED`/rollout 0. Mutation response chiếu trạng thái publish thành `PUBLISHED`; GET catalog cũ vẫn trả trạng thái vật lý `ACTIVE`. Không sửa nội dung đã publish; thay đổi tạo code mới và version mới. API không có PATCH/PUT nội dung.
- Nháp plan/trial lưu riêng trong `ops.app_config`: khóa `cms.plan.<uuid>` / `cms.trial.<uuid>`, envelope `{schemaVersion:1,id,kind,status,input}`, kiểm schema khi đọc. Publish mới INSERT vào bảng catalog thật với cùng UUID; không để nháp lọt vào consumer. Nháp cũng có thể ngừng dùng mà không tạo catalog thật.
- Plan phải có sẵn, không tạo plan hoặc sản phẩm Store/giá trong luồng này. Quota/features/rank của version mới không sửa quyền lợi/version cũ. Trial mặc định vẫn theo config hiện có; publish policy code khác **không** tự đổi default policy code.
- Billing `availableFrom` là ISO datetime có timezone; plan map trực tiếp sang `available_from`, trial map sang `published_at`. Consumer hiện có lọc thời điểm hiệu lực nên không cần job mới. Ngừng bản hẹn tương lai dùng `retiredAt=max(now,availableFrom/publishedAt)` để đáp ứng constraint và không xuất hiện khi đến hạn.
- **Giới hạn chuyển trial:** unique active policy theo code chỉ cho một bản active. Publish cùng code còn active trả 409, không tự retire bản cũ. Phải retire rõ ràng rồi publish bản mới; chưa có thao tác chuyển version theo lịch nguyên tử, nên operator cần tránh tạo khoảng trống hiệu lực. Plan còn trial active tham chiếu không được retire (409), do onboarding hiện tại vẫn có thể cấp trial theo code đó.
- Milestones và notification templates không có version trong schema, chưa hỗ trợ ghi; UI thông báo, API trả 422.
- Transaction bao gồm ghi catalog/marker và audit. Advisory transaction lock tuần tự hóa CMS writers; publish đồng thời một lần thành công, một lần 409. Không hard-delete nghiệp vụ.
- RBAC ở service mới: CONTENT/SUPER_ADMIN cho missions; BILLING_OPS/OPS/SUPER_ADMIN cho plan/trial. Legacy `ADMIN` không vượt quyền ghi. Guard vẫn xác thực admin; client không chọn actor.
- Lý do bắt buộc trim 1–80 ký tự, lưu `AdminAuditEvent.reasonCode`; action `CATALOG_DRAFT_CREATE`, `CATALOG_PUBLISH`, `CATALOG_RETIRE`, entityType = kind, entityId = code mission hoặc UUID billing. Chỉ mutation thành công có audit tương ứng; lỗi rollback cả hai.

## Route và JSON chính xác

Prefix `/admin/v1/catalog`, header `Authorization: Bearer <admin-token>`. JSON dưới đây dùng `<uuid>`, `<timestamp>` làm placeholder giá trị động; keys và kiểu là contract. Mọi POST thành công trả HTTP **201**, GET trả **200**. Envelope HTTP `{ "data": ... }` do interceptor hiện có.

| Method | Route                         | Quyền                                       |
| ------ | ----------------------------- | ------------------------------------------- |
| POST   | `/missions`                   | CONTENT / SUPER_ADMIN                       |
| POST   | `/missions/:code/publish`     | CONTENT / SUPER_ADMIN                       |
| POST   | `/missions/:code/retire`      | CONTENT / SUPER_ADMIN                       |
| POST   | `/plan-versions`              | BILLING_OPS / OPS / SUPER_ADMIN             |
| POST   | `/plan-versions/:id/publish`  | BILLING_OPS / OPS / SUPER_ADMIN             |
| POST   | `/plan-versions/:id/retire`   | BILLING_OPS / OPS / SUPER_ADMIN             |
| POST   | `/trial-policies`             | BILLING_OPS / OPS / SUPER_ADMIN             |
| POST   | `/trial-policies/:id/publish` | BILLING_OPS / OPS / SUPER_ADMIN             |
| POST   | `/trial-policies/:id/retire`  | BILLING_OPS / OPS / SUPER_ADMIN             |
| GET    | `/publishing/:kind`           | Cùng quyền ghi tương ứng; chỉ liệt kê DRAFT |

`GET /:kind?offset=0&limit=100` cũ vẫn dùng để đọc catalog thật; thêm OPS vào quyền đọc. GET drafts chưa có pagination, UI list catalog thật vẫn tải 100 dòng đầu (giới hạn sẵn có, chưa bổ sung phân trang server cho drafts).

### Mission

Request `POST /missions`:

```json
{
  "code": "CMS-PLAY-V2",
  "stage": "CHILD",
  "minAgeDays": 0,
  "maxAgeDays": 365,
  "minPregWeek": null,
  "maxPregWeek": null,
  "category": "PLAY",
  "suggestedScope": "CHILD",
  "roleFit": "ANY_PARENT",
  "hearts": 3,
  "durationMin": 5,
  "multiChildOk": true,
  "requestable": true,
  "titleI18n": { "vi": "Chơi cùng bé", "en": "Play together" },
  "descI18n": { "vi": "Dành thời gian bên bé", "en": "Spend time together" },
  "tags": ["play"],
  "weight": 10,
  "version": 2,
  "reason": "Thêm phiên bản nội dung"
}
```

`memoryPromptI18n` tùy chọn, nếu có phải đủ `vi` và `en`. Không nhận `status`/`rolloutPct` lúc tạo. Stage `PREGNANCY|CHILD|ANY`; category theo schema seed (không CUSTOM); scope `CHILD|MULTI_CHILD|FAMILY|COUPLE`; roleFit `ANY_PARENT|PREGNANT_MOTHER|PARTNER_OF_PREGNANT|TOGETHER`. Scope COUPLE yêu cầu role TOGETHER. Age không âm/Int32; tuần thai 1–42; range không đảo; Hearts 1–10; duration/weight 1–32767; version 1–2147483647. Object strict từ chối field lạ, bản dịch không rỗng.

Response tạo (prompt không truyền → null):

```json
{
  "data": {
    "kind": "missions",
    "item": {
      "id": "<uuid>",
      "code": "CMS-PLAY-V2",
      "stage": "CHILD",
      "minAgeDays": 0,
      "maxAgeDays": 365,
      "minPregWeek": null,
      "maxPregWeek": null,
      "category": "PLAY",
      "suggestedScope": "CHILD",
      "roleFit": "ANY_PARENT",
      "hearts": 3,
      "durationMin": 5,
      "multiChildOk": true,
      "requestable": true,
      "titleI18n": { "vi": "Chơi cùng bé", "en": "Play together" },
      "descI18n": {
        "vi": "Dành thời gian bên bé",
        "en": "Spend time together"
      },
      "memoryPromptI18n": null,
      "tags": ["play"],
      "weight": 10,
      "rolloutPct": 0,
      "status": "DRAFT",
      "version": 2,
      "updatedAt": "<timestamp>",
      "createdAt": "<timestamp>",
      "deletedAt": null
    }
  }
}
```

Publish request `{"reason":"Duyệt nội dung","rolloutPct":80}`; rolloutPct tùy chọn mặc định 100, 1–100. Response cùng đầy đủ keys mission trên, `status:"PUBLISHED"`, `rolloutPct:80`, updatedAt mới; nội dung giữ nguyên. Retire request `{"reason":"Ngừng mẫu cũ"}`, response cùng keys với `status:"RETIRED"`, `rolloutPct:0`, updatedAt mới. Publish lại bản đã publish/retire → 409; tạo lại code cũ → 409. Retire lặp được, không xóa lịch sử.

### Plan version

Request `POST /plan-versions`:

```json
{
  "planId": "<uuid-plan-co-san>",
  "version": 2,
  "quotas": { "children": 3, "storageBytes": 1000000000 },
  "features": { "circle": true },
  "entitlementRank": 20,
  "reason": "Tạo quyền lợi phiên bản mới"
}
```

Quota là object giá trị số nguyên không âm, không vượt MAX_SAFE_INTEGER; features là object boolean. Keys capability theo hệ thống server đang hỗ trợ, không suy quyền theo tên plan. Rank không âm Int32; version dương Int32. Không có giá hoặc Store product trong request.

Response nháp:

```json
{
  "data": {
    "kind": "plan-versions",
    "item": {
      "id": "<uuid-draft>",
      "planId": "<uuid-plan-co-san>",
      "version": 2,
      "quotas": { "children": 3, "storageBytes": 1000000000 },
      "features": { "circle": true },
      "entitlementRank": 20,
      "status": "DRAFT"
    }
  }
}
```

Publish request `{"reason":"Duyệt quyền lợi","availableFrom":"2026-10-22T00:00:00.000Z"}`. Response:

```json
{
  "data": {
    "kind": "plan-versions",
    "item": {
      "id": "<uuid-draft>",
      "planId": "<uuid-plan-co-san>",
      "version": 2,
      "quotas": { "children": 3, "storageBytes": 1000000000 },
      "entitlementRank": 20,
      "features": { "circle": true },
      "availableFrom": "2026-10-22T00:00:00.000Z",
      "retiredAt": null,
      "createdAt": "<timestamp-publish>",
      "updatedAt": "<timestamp-publish>",
      "deletedAt": null,
      "status": "PUBLISHED"
    }
  }
}
```

Retire request `{"reason":"Ngừng bán version cũ"}`. Nếu đã publish, response cùng keys, `retiredAt:<timestamp>`/`updatedAt:<timestamp>`/`status:"RETIRED"`; nếu còn nháp, response nháp với status RETIRED (không có bản ghi billing, không có timestamps catalog).

### Trial policy

Request `POST /trial-policies`:

```json
{
  "code": "TRIAL-NEW",
  "version": 1,
  "planVersionId": "<uuid-plan-version>",
  "durationSeconds": 604800,
  "reminderOffsetsSeconds": [86400],
  "reason": "Tạo policy mới"
}
```

Duration số nguyên dương không quá MAX_SAFE_INTEGER; offsets số nguyên dương Int32, phải nhỏ hơn duration. Plan version phải có sẵn và còn hiệu lực tại thời điểm trial bắt đầu. Không hard-code thời hạn 7 ngày trong logic/UI; ví dụ 604800 là dữ liệu đầu vào.

Response nháp:

```json
{
  "data": {
    "kind": "trial-policies",
    "item": {
      "id": "<uuid-draft>",
      "code": "TRIAL-NEW",
      "version": 1,
      "planVersionId": "<uuid-plan-version>",
      "durationSeconds": 604800,
      "reminderOffsetsSeconds": [86400],
      "status": "DRAFT"
    }
  }
}
```

Publish request `{"reason":"Duyệt dùng thử","availableFrom":"2026-10-22T00:00:00.000Z"}`. Response:

```json
{
  "data": {
    "kind": "trial-policies",
    "item": {
      "id": "<uuid-draft>",
      "code": "TRIAL-NEW",
      "version": 1,
      "planVersionId": "<uuid-plan-version>",
      "durationSeconds": "604800",
      "reminderOffsetsSeconds": [86400],
      "active": true,
      "publishedAt": "2026-10-22T00:00:00.000Z",
      "retiredAt": null,
      "createdAt": "<timestamp-publish>",
      "updatedAt": "<timestamp-publish>",
      "deletedAt": null,
      "status": "PUBLISHED"
    }
  }
}
```

Lưu ý duration trong bản ghi thật là BigInt → chuỗi thập phân JSON; bản nháp là số safe integer. Retire request `{"reason":"Ngừng policy cũ"}`. Response published có đầy đủ keys trên với `active:false`, `retiredAt:<timestamp>`, updatedAt mới, `status:"RETIRED"`. Retire draft chỉ trả các keys nháp với status RETIRED.

### Danh sách nháp

`GET /publishing/plan-versions` → `{"data":{"kind":"plan-versions","items":[<item-nhap-nhu-tren>]}}`. Mission/trial tương tự; mission item có đủ fields/timestamps của hàng mission; billing item có input + UUID + status. Chỉ trả DRAFT, không thay thế list catalog thật.

### Mã lỗi

Envelope hiện có: `{"error":{"code":"<code>","message":"<localized-message>"},"path":"<request-path>","timestamp":"<timestamp>"}`; `requestId` có khi middleware cấp; lỗi ValidationPipe hiện có có thể thêm `details`.

| HTTP | Code                           | Điều kiện                                                                                                                |
| ---- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 400  | VALIDATION_ERROR               | Field lạ/sai kiểu, lý do thiếu/trắng/>80, range/translation/hearts/offset sai, UUID billing sai, thiếu/sai availableFrom |
| 401  | ADMIN_UNAUTHORIZED             | Thiếu token (các lỗi session cụ thể dùng guard/auth hiện có)                                                             |
| 403  | ADMIN_FORBIDDEN                | Role không có quyền catalog/action                                                                                       |
| 404  | ADMIN_CATALOG_NOT_FOUND        | Entry/plan/FK target không tồn tại hoặc bị xóa/plan inactive khi publish                                                 |
| 409  | ADMIN_CATALOG_CONFLICT         | Code/version trùng, publish lại, trial code còn active, retire plan còn trial active, xung đột writer/FK                 |
| 409  | ADMIN_CATALOG_DRAFT_INVALID    | Nháp AppConfig không đúng schema/version                                                                                 |
| 422  | ADMIN_CATALOG_UNSUPPORTED      | Kind không hỗ trợ version publishing, gồm milestone/notification                                                         |
| 422  | ADMIN_CATALOG_PLAN_UNAVAILABLE | Trial trỏ plan không khả dụng ở availableFrom                                                                            |
