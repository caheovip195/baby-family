## Contract chính xác

Request không có JSON body:

```http
GET /metrics
Authorization: Bearer <METRICS_TOKEN>
```

`METRICS_TOKEN` là secret cấu hình dài 32–512 ký tự. Không dùng JWT hoặc query token. Root route `/metrics`, không phải `/api/v1/metrics`.

Success: HTTP 200, `Content-Type: text/plain; version=0.0.4; charset=utf-8`, `Cache-Control: no-store`, raw Prometheus text. Không có JSON success. Counter `baby_family_http_requests_total{route,status}` và histogram `baby_family_http_request_duration_seconds_{bucket,count,sum}` (giây, cumulative buckets `0.005,0.01,0.025,0.05,0.1,0.25,0.5,1,2.5,5,10,+Inf`). Bốn gauge:

```text
baby_family_jobs_failed_recent <integer>
baby_family_job_attempts_timed_out_recent <integer>
baby_family_jobs_backlog <integer>
baby_family_outbox_backlog <integer>
```

Định nghĩa chính xác và cấu hình scrape/cảnh báo trong [observability.md](../observability.md). Gauges là toàn DB, không sum qua replicas; HTTP metrics riêng từng process. Không có tenant/user label hoặc dữ liệu nội dung. Window lỗi 900 giây; backlog gồm cả item chờ retry/consumer. Không phải queue-depth BullMQ.

Lỗi qua filter production, mặc định tiếng Việt, `requestId` động và `timestamp` ISO UTC:

```json
{
  "error": {
    "code": "METRICS_UNAUTHORIZED",
    "message": "Vui lòng đăng nhập lại để tiếp tục."
  },
  "requestId": "<UUID>",
  "path": "/metrics",
  "timestamp": "<ISO-8601 UTC>"
}
```

| Điều kiện           | HTTP | error.code           | error.message mặc định vi                              |
| ------------------- | ---- | -------------------- | ------------------------------------------------------ |
| Chưa cấu hình token | 404  | METRICS_DISABLED     | Không tìm thấy nội dung yêu cầu.                       |
| Thiếu/sai Bearer    | 401  | METRICS_UNAUTHORIZED | Vui lòng đăng nhập lại để tiếp tục.                    |
| DB lỗi              | 503  | METRICS_UNAVAILABLE  | Dịch vụ tạm thời không khả dụng. Vui lòng thử lại sau. |

`Accept-Language` dùng cơ chế locale chung. Token sai/thiếu không query DB; so sánh digest constant-time. Không có mã lỗi ứng dụng khác mới. Request ID đầu vào chỉ chấp nhận UUID; nếu sai sinh UUID và trả `X-Request-Id`. JSON log có level chữ, time epoch ms, requestId, route template, status, durationMs; userId bỏ hoàn toàn.

## DI/job registration

Đã wiring API qua module mới, **không còn dòng cần thêm** vào application.providers hoặc worker module. Các dòng chính xác đã đặt trong `ObservabilityModule`:

```ts
imports: [DatabaseModule],
controllers: [MetricsController],
providers: [
  { provide: OBSERVABILITY_REPOSITORY, useClass: ObservabilityRepository },
  { provide: OBSERVABILITY_SERVICE, useClass: ObservabilityService },
  { provide: ERROR_REPORTER, useClass: ErrorReporterService },
  RequestMetricsMiddleware,
],
exports: [OBSERVABILITY_SERVICE, ERROR_REPORTER],
```

Module là global để filter ở parent inject reporter. `AppModule.imports` thêm `ObservabilityModule`. Middleware đăng ký `consumer.apply(RequestMetricsMiddleware).forRoutes('{*path}')`; bootstrap exclude thêm `{ path: 'metrics', method: RequestMethod.ALL }`. Logger factory gọi `httpLoggingOptions(LOG_LEVEL, LOG_FORMAT)`. Không đăng ký job/cron/handler mới: metric là read-only aggregate lịch sử bền vững hiện có.

Worker chưa dùng factory/hook mới vì worker module được giữ nguyên. Khi có task worker observability riêng, phải áp cấu hình logger/hook vào composition root đó; hiện không tuyên bố giám sát đầy đủ worker/tracing/provider startup errors.
