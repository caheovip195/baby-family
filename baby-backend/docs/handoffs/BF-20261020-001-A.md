## Hành vi và cấu hình

- Controller → Symbol service interface → service → Symbol repository interface → repository → model có sẵn. Không Prisma trong service/controller. Resolver/verifier có interface để inject JWKS giả; mặc định cache `createRemoteJWKSet`, URL HTTPS lấy từ env đáng tin cậy, không lấy URL từ JWT/client.
- RS256; bắt buộc `sub/iss/aud/iat/exp`, kiểm chữ ký/issuer/audience/hết hạn và iat tương lai; Apple có nonce thì so SHA-256 hex của raw nonce. `fullName` là chuỗi tùy chọn tối đa 80 ký tự, chỉ dùng lúc tạo tài khoản; không phải bằng chứng danh tính.
- Email chỉ lưu vào AuthIdentity khi JWT đã verify và email_verified hợp lệ; không tìm/gộp tài khoản theo email. Mỗi provider tối đa một identity active qua API link.
- Tạo user + identity + session trong một transaction. Token được cấp bằng AuthTokenService hiện có: access ES256 900 giây; opaque refresh 32 byte, DB chỉ SHA-256; trượt 90 ngày, tuyệt đối 365 ngày. Response dùng UserResponseDto và profile avatar service hiện có (optional, mặc định URL null). Social request không nhận thông tin device nên platform/appVersion null.
- User ACTIVE được đăng nhập; DELETION_PENDING chỉ khi còn grace có deletion request SCHEDULED; user khóa/xóa bị từ chối. Quản lý identity/social reauth yêu cầu user ACTIVE và session hiện hành.
- Link/unlink/reauth kiểm lại session + token version sau khóa user trong transaction; unlink đếm identity active và soft-delete cùng transaction. PHONE có sẵn được tính khi bảo vệ phương thức cuối; API DELETE này chỉ hỗ trợ apple/google để không thay đổi luồng OTP điện thoại.
- Identity đã gỡ vẫn giữ unique toàn cục của schema: đăng nhập với subject đó trả 403 AUTH_ACCOUNT_UNAVAILABLE; cùng chủ có thể relink bằng proof mới, chủ khác nhận 409 IDENTITY_IN_USE. Không tự chuyển quyền sở hữu/tạo tài khoản khác cho tombstone.
- Không tạo job/cron, bảng hay seed mới.

Ví dụ cấu hình (mỗi provider opt-in, thiếu bất kỳ trường nào trả 503):

```dotenv
AUTH_APPLE_JWKS_URL=https://appleid.apple.com/auth/keys
AUTH_APPLE_ISSUER=https://appleid.apple.com
AUTH_APPLE_CLIENT_ID=<bundle-id-hoac-service-id>
AUTH_GOOGLE_JWKS_URL=https://www.googleapis.com/oauth2/v3/certs
AUTH_GOOGLE_ISSUER=https://accounts.google.com
AUTH_GOOGLE_CLIENT_ID=<oauth-client-id>
```

Mỗi provider hiện cấu hình một issuer/client ID chính xác. Nếu cần nhiều client ID iOS/Android/web, đây là phần mở rộng cấu hình tiếp theo, chưa hỗ trợ danh sách phân cách dấu phẩy. Giữ các env AUTH_JWT_PRIVATE_KEY/AUTH_SECRET_PEPPER hiện có để phát hành phiên. Không yêu cầu Valkey/SMTP cho social sign-in hoặc social reauth; OTP vẫn dùng dependency cũ.

Nguồn đối chiếu: đặc tả nghiệp vụ §7.1, §9.1, SET; kỹ thuật §5.1–5.4. Kiểm tra claim theo [Apple](https://developer.apple.com/documentation/signinwithapple/authenticating-users-with-sign-in-with-apple) và [Google](https://developers.google.com/identity/openid-connect/openid-connect).

## HTTP contract chính xác

Prefix thực tế `/api/v1`. Mọi route sau áp throttle 30/phút/IP qua ThrottlerGuard chung của ứng dụng. Thành công có envelope `data`, 204 không body. Link/unlink/reauth/list yêu cầu `Authorization: Bearer <accessToken>`; đăng nhập public.

### Đăng nhập (200)

`POST /auth/apple`

```json
{
  "identityToken": "<Apple JWT>",
  "nonce": "<raw nonce, tùy chọn>",
  "fullName": "Tên hiển thị, tùy chọn"
}
```

`POST /auth/google`

```json
{ "idToken": "<Google JWT>" }
```

Cả hai trả:

```json
{
  "data": {
    "accessToken": "<ES256 JWT>",
    "refreshToken": "<opaque token>",
    "expiresIn": 900,
    "user": {
      "id": "<uuid>",
      "avatarAssetId": null,
      "avatarUrl": null,
      "avatarUrlExpiresAt": null,
      "displayName": "Baby Family",
      "locale": "vi",
      "timezone": "Asia/Ho_Chi_Minh",
      "createdAt": "<ISO UTC>",
      "updatedAt": "<ISO UTC>"
    },
    "isNewUser": true
  }
}
```

Lần sau cùng provider/subject trả cùng user, `isNewUser:false`, cặp token mới. `displayName` dùng fullName ở Apple lần đầu nếu có; user cũ giữ hồ sơ, avatar có thể là URL ký cùng expiry từ profile image service.

### Reauth social (200)

`POST /auth/reauth/apple` cùng JSON Apple phía trên; `POST /auth/reauth/google` cùng JSON Google. JWT nhà cung cấp phải thuộc identity active của actor hiện tại.

```json
{
  "data": {
    "reauthToken": "<ES256 typ=reauth+jwt, scope=reauth, sub/sid/ver của actor>",
    "expiresAt": "<ISO UTC, sau tối đa 300 giây>"
  }
}
```

Bổ sung này cho tài khoản social chưa có PHONE lấy được reauth proof. Token được verify bằng ReauthService hiện có, không giảm kiểm tra reauth.

### Liệt kê (200)

`GET /me/sign-in-methods`

```json
{
  "data": [
    {
      "provider": "GOOGLE",
      "linkedAt": "<ISO UTC>",
      "maskedHint": "a***@example.com"
    },
    { "provider": "PHONE", "linkedAt": "<ISO UTC>", "maskedHint": "***1234" }
  ]
}
```

Provider uppercase APPLE/GOOGLE/PHONE, sắp createdAt rồi id. Email không có → maskedHint null; không trả subject/email thô.

### Liên kết (204, không body)

`POST /me/identities/apple`

```json
{
  "identityToken": "<Apple JWT>",
  "nonce": "<raw nonce, tùy chọn>",
  "fullName": "Tên, tùy chọn và không đổi hồ sơ khi link",
  "reauthToken": "<proof của session hiện tại>"
}
```

`POST /me/identities/google`

```json
{ "idToken": "<Google JWT>", "reauthToken": "<proof của session hiện tại>" }
```

Link cùng identity cùng user idempotent. Link identity khác cùng provider đã active → 409; identity của user khác kể cả tombstone → 409.

### Gỡ (204, không body)

`DELETE /me/identities/apple` hoặc `/me/identities/google`

```json
{ "reauthToken": "<proof của session hiện tại>" }
```

Provider chưa liên kết → 204 nếu proof/session hợp lệ; gỡ phương thức cuối → 409. Gỡ không revoke các phiên đã cấp, giữ hành vi quản lý phiên riêng hiện có.

## Mã lỗi

Error envelope dùng HttpExceptionFilter hiện có (`error.code/message/details?`, metadata requestId/timestamp/path tùy filter).

| HTTP | code                             | Điều kiện                                                                                                       |
| ---- | -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 503  | AUTH_PROVIDER_UNAVAILABLE        | Thiếu cấu hình provider/phát hành phiên; JWKS URL không HTTPS, fetch/JWKS hỏng hoặc provider tạm không sẵn sàng |
| 401  | AUTH_IDENTITY_INVALID            | JWT/chữ ký/claims/aud/iss/exp/nonce sai, key không khớp                                                         |
| 403  | AUTH_ACCOUNT_UNAVAILABLE         | Account bị khóa/xóa, tombstone identity; mutation/reauth không có session ACTIVE phù hợp                        |
| 409  | IDENTITY_IN_USE                  | Subject đã thuộc user khác, kể cả identity đã soft-delete                                                       |
| 409  | IDENTITY_PROVIDER_ALREADY_LINKED | User đã có subject khác active của provider đó                                                                  |
| 409  | LAST_SIGN_IN_METHOD              | Gỡ sẽ không còn phương thức đăng nhập                                                                           |
| 400  | IDENTITY_PROVIDER_INVALID        | DELETE provider ngoài apple/google                                                                              |
| 401  | REAUTH_REQUIRED                  | Reauth JWT sai/hết hạn/sai session-user-version; access JWT không thể dùng thay                                 |
| 401  | REAUTH_IDENTITY_REQUIRED         | Social proof không thuộc identity active của actor                                                              |
| 503  | REAUTH_UNAVAILABLE               | Chưa có cấu hình ký/verify reauth                                                                               |
| 400  | VALIDATION_ERROR                 | DTO thiếu/sai kiểu/quá dài/field ngoài whitelist, theo filter hiện có                                           |
| 401  | UNAUTHORIZED                     | AccessTokenGuard thiếu/sai/hết hạn token hoặc session bị revoke, theo filter hiện có                            |
| 429  | TOO_MANY_REQUESTS                | Throttle chung của ứng dụng, theo filter hiện có                                                                |
