## VOICE

Schema đã có `MemoryKind.VOICE`, AUDIO, durationMs; worker audio và media signer đã có. Policy MIME hiện hữu: `audio/mp4`, `audio/x-m4a`, `audio/aac`, `audio/mpeg`. Không thay worker/media policy. Client upload với `purpose: MEMORY`, chờ asset READY rồi tạo ký ức; durationMs do worker probe, không lấy từ request tạo ký ức.

`POST /api/v1/memories`, Bearer + `Idempotency-Key` UUID, response 201. Request ví dụ đầy đủ tối thiểu:

```json
{
  "familyId": "11111111-1111-4111-8111-111111111111",
  "kind": "VOICE",
  "assetIds": ["22222222-2222-4222-8222-222222222222"],
  "childIds": ["33333333-3333-4333-8333-333333333333"],
  "occurredAt": "2026-10-21T03:00:00.000Z",
  "visibility": "PARENTS",
  "body": "Giọng nói của con"
}
```

`body` tùy chọn. Các field hiện hữu của CreateMemoryDto vẫn giữ nguyên. Chỉ đúng một AUDIO READY có durationMs hữu hạn >0; asset vẫn qua quyền sở hữu/family/visibility hiện hữu. Kiểm `audioMaxSec` từ plan catalog hiện tại, không theo tên gói; thiếu capability fail closed. Kiểm lại khi publish draft và thay asset, không cho bỏ audio cuối hoặc gắn thêm ảnh/audio thứ hai. Quota ảnh bằng 0 không cấm VOICE.

Response 201 và `GET /api/v1/memories/:id` giữ toàn bộ shape hiện hữu; ví dụ một VOICE không có reaction/perspective:

URL trên chỉ minh họa; runtime ký URL variant `a`, TTL 3600 giây. `durationSec = durationMs / 1000`, giữ phần thập phân; kinds khác trả null. Feed `GET /api/v1/families/:fid/feed` giữ `{data: MemoryResponseDto[], nextCursor: string|null}`; timeline `GET /api/v1/families/:fid/timeline?childId=...` giữ contract hiện hữu và card `type: MEMORY` chứa `memory: MemoryResponseDto`. Cả ba dùng chung projection nên durationSec và asset nghe có ở cả ba.

Mã lỗi mới:

| HTTP | code                          | Điều kiện                                              |
| ---- | ----------------------------- | ------------------------------------------------------ |
| 422  | MEMORY_VOICE_ASSET_REQUIRED   | Không đúng một asset                                   |
| 422  | MEMORY_VOICE_ASSET_INVALID    | Không phải READY AUDIO hoặc không có durationMs hợp lệ |
| 422  | QUOTA_AUDIO_DURATION_EXCEEDED | durationMs > audioMaxSec × 1000                        |
| 402  | SUBSCRIPTION_REQUIRED         | Plan không có audioMaxSec                              |

Asset không hợp lệ/không quyền có thể bị chặn sớm bằng mã ACL/asset hiện hữu. Client gửi durationSec/durationMs vào create bị 400 VALIDATION_ERROR bởi whitelist. Các quyền, quota storage/memoryCount, idempotency và lỗi existing giữ nguyên.

## FAM-08

`GET /api/v1/me/families` (Bearer), 200:

```json
{
  "data": {
    "items": [
      {
        "familyId": "11111111-1111-4111-8111-111111111111",
        "name": "Nhà mình",
        "role": "PARENT",
        "status": { "family": "ACTIVE", "membership": "ACTIVE" },
        "coverUrl": null,
        "isDefault": true
      },
      {
        "familyId": "66666666-6666-4666-8666-666666666666",
        "name": "Nhà người thân",
        "role": "CIRCLE",
        "status": { "family": "ACTIVE", "membership": "PAUSED" },
        "coverUrl": null,
        "isDefault": false
      }
    ]
  }
}
```

Parent hiện tại đứng trước Circle; thứ tự trong mỗi nhóm theo joinedAt/id. Family status dùng enum hiện hữu như WAITING_PARTNER, ACTIVE, PARTNER_LEFT, DELETION_SCHEDULED. Circle membership gồm ACTIVE, PAUSED, SUSPENDED_PLAN; tư cách đã kết thúc/xóa và family DELETED/xóa mềm bị loại. Không trả trẻ, grants hay nội dung. Parent có thể nhận coverUrl đã ký nếu có ảnh và signer; Circle luôn null vì ảnh bìa chưa có ACL theo trẻ. Listing không cấp quyền nội dung và không thay entitlement.

`PUT /api/v1/me/default-family` (Bearer), request:

```json
{ "familyId": "66666666-6666-4666-8666-666666666666" }
```

Response 200:

```json
{ "data": { "familyId": "66666666-6666-4666-8666-666666666666" } }
```

Lưu trong `UserSetting.notificationPrefs.familyContext = {version:1,defaultFamilyId}`; SQL atomic, không migration. Giữ các preference khác và chống stale notification update ghi đè context. Mặc định chưa lưu/không còn membership hợp lệ thì GET fallback item đầu, không tự ghi fallback. PUT chỉ chọn ngữ cảnh đã có membership, hoàn toàn không chuyển/tạo Parent nhà khác (BR-057).

Lỗi: 401 UNAUTHORIZED thiếu/sai Bearer; 400 VALIDATION_ERROR UUID/field lạ; 404 NOT_FOUND nếu family không thuộc, đã rời/xóa, user/settings xóa mềm. Không phân biệt existence của family ngoài quyền.

## FAM-07 catalog múi giờ

`GET /api/v1/catalog/timezones?locale=vi|en`, public, mặc định vi, 200. Response đầy đủ là `{data:{version:"1",items:[...]}}`; mỗi item chính xác ba field. Ví dụ một item thuộc mảng:

```json
{
  "id": "Asia/Ho_Chi_Minh",
  "label": "Việt Nam — Giờ Đông Dương",
  "offsetMinutes": 420
}
```

Nhãn múi giờ do ICU dịch theo locale, phần tên địa điểm phổ biến nằm trong config; ví dụ nhãn có thể thay đổi theo ICU runtime. Danh sách gồm thị trường mục tiêu trước rồi toàn bộ `Intl.supportedValuesOf('timeZone')`, loại trùng id, thêm UTC. Version config là `TIMEZONE_CATALOG.version`; phần IANA bổ sung và quy tắc DST phụ thuộc tzdata/ICU runtime, không phải snapshot bất biến. Offset là phút so với UTC tại thời điểm request (âm ở phía Tây, tính DST), không phải offset cố định cho tương lai.

`PATCH /api/v1/families/:fid`, Bearer Parent, request:

```json
{ "timezone": "Asia/Ho_Chi_Minh" }
```

Response 200 giữ FamilyResponseDto:

```json
{
  "data": {
    "id": "11111111-1111-4111-8111-111111111111",
    "name": "Nhà mình",
    "status": "ACTIVE",
    "timezone": "Asia/Ho_Chi_Minh",
    "contentLocale": "vi",
    "coverAssetId": null,
    "coverUrl": null,
    "coverUrlExpiresAt": null,
    "createdAt": "2026-10-21T03:00:00.000Z",
    "updatedAt": "2026-10-21T03:01:00.000Z"
  }
}
```

DTO và service dùng chung `isCatalogTimezone`; nhận IANA/alias runtime hợp lệ và UTC, từ chối numeric offsets/abbreviation như EST/zone không tồn tại/null. Invalid locale/zone: 400 VALIDATION_ERROR; thiếu auth 401; Circle/người ngoài PATCH: 404 NOT_FOUND theo access policy hiện hữu. Các lifecycle/entitlement errors khác giữ nguyên.
