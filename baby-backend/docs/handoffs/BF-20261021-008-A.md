# BF-20261021-008-A — Backend media client processing

Trạng thái: đã triển khai và xác minh chức năng; `npm run check` còn lỗi công cụ watcher do môi trường (chi tiết bên dưới). Phạm vi backend; không commit, không sửa app, hai nhật ký, checklist hay docs/api.md. Những file này vốn có thay đổi của phiên khác được giữ nguyên.

## Kết quả triển khai

- Client tạo/nén mọi file; presign riêng file chính và variants. IMAGE bắt buộc m1080+t320 (l2048 tùy chọn), VIDEO poster+t320, AUDIO gửi variants rỗng.
- HEAD xác minh toàn bộ objects; sai thì FAILED, trả reservation và xóa objects; thành công READY ngay, xác nhận quota và publish ký ức đủ asset READY trong cùng transaction.
- Dùng chung `MediaRepository.publishReadyMemories` với worker, không nhân bản logic/outbox publish. Không phát media.asset_uploaded ở phiên client.
- Quota giữ chỗ tính từng object + dung sai; alias VIDEO v1080/AUDIO a dùng cùng file chính, không double-count hoặc upload lại.
- URL xem theo code, download original nhận alias file chính; tài khoản avatar cũng dùng biến thể client và giữ raw đã nén, không chạy processor đường mới.
- Mặc định MEDIA_SERVER_PROCESSING=disabled; legacy chỉ bật có chủ đích. Legacy worker vẫn có attempt/history/lease/fencing/recovery cũ.

## Contract chính xác

Contract, ví dụ request/response, HTTP status, quy tắc từng kind, mã lỗi và rủi ro đầy đủ ở [media-client-processing.md](../media-client-processing.md). Các route tương đối prefix `/api/v1`, payload dưới đây nằm trong envelope `{ "data": ... }` hiện hành.

| Route                            | Request                                                                                                                                              | HTTP / response payload                                                                                                        |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| POST /media/upload-intents       | Header Idempotency-Key UUID; `{familyId,kind,purpose,mime,size,sha256,width?,height?,durationMs?,variants:[{code,mime,size,sha256,width?,height?}]}` | 201 `{assetId,status,deduplicated,upload?,variantUploads?:[{code,upload:{mode:'single',url,method:'PUT',headers,expiresAt}}]}` |
| POST /media/:id/parts            | `{partNumbers?:number[]}` giữ nguyên                                                                                                                 | Response multipart giữ nguyên                                                                                                  |
| POST /media/:id/complete         | `{}` single hoặc `{parts:[{n,etag}]}` multipart                                                                                                      | 202 `{assetId,status:'READY'}` client; replay trả trạng thái hiện tại                                                          |
| GET /media/:id                   | Không body                                                                                                                                           | 200 `{assetId,kind,purpose,status,width,height,durationMs,blurhash,urls,urlsExpireAt}`                                         |
| POST /media/urls                 | `{assetIds:[...]}`                                                                                                                                   | 200 `{items:[projection],unavailableIds:[...]}`                                                                                |
| POST /memories/:id/download-urls | Không body; quyền/rate limit cũ                                                                                                                      | 200 `{items:[{assetId,kind,url,expiresAt,fileName}]}`; VIDEO/AUDIO mới dùng key chính                                          |
| POST /me/avatar/upload-intents   | Header Idempotency-Key UUID; `{purpose:'AVATAR',mime,size,sha256,width?,height?,variants:[{code,mime,size,sha256,width?,height?}]}`                  | 201 `{assetId,status,upload?,variantUploads?}`                                                                                 |
| POST /me/avatar/:id/complete     | `{}`                                                                                                                                                 | 200 `{assetId,status:'READY'}`                                                                                                 |

`upload` file chính giữ single/multipart cũ: single `{mode:'single',method:'PUT',url,headers,expiresAt}`; multipart `{mode:'multipart',partSize,partCount,parts:[{n,url}],expiresAt}`. Dedup/replay đã kết thúc không ký lại URL. AUDIO response variantUploads là mảng rỗng. SHA-256 mỗi PUT được ký trong header.

Mã lỗi media mới: 422 `MEDIA_VARIANTS_REQUIRED`, `MEDIA_VARIANT_INVALID`, `MEDIA_VARIANT_TYPE_UNSUPPORTED`, `MEDIA_VARIANT_TOO_LARGE`, `MEDIA_DIMENSIONS_EXCEEDED`, `MEDIA_VARIANT_DIMENSIONS_EXCEEDED`, `MEDIA_DURATION_EXCEEDED`, `UPLOAD_MISSING`, `UPLOAD_VARIANT_MISSING`, `UPLOAD_SIZE_MISMATCH`, `UPLOAD_VARIANT_SIZE_MISMATCH`, `UPLOAD_MIME_MISMATCH`, `UPLOAD_VARIANT_MIME_MISMATCH`. Avatar giữ lỗi HEAD riêng 422 `UPLOAD_VARIANT_METADATA_MISMATCH` cho MIME; main avatar cũng được kiểm như variant orig. 402 `QUOTA_STORAGE_EXCEEDED`, 409 `IDEMPOTENCY_KEY_REUSED`/`UPLOAD_EXPIRED`/`UPLOAD_REJECTED`, auth/ACL và validation400 giữ nguyên.

## Review và giới hạn

BACKEND chủ trì, TESTER triển khai/xác minh tests và QUALITY review media độc lập; profile sub-agent review chéo. Finding đã xử lý: download alias VIDEO/AUDIO, guard legacy cleanup recovery, hash idempotency không phụ thuộc thứ tự trường JSON/variant array; có regression đạt.

Rủi ro theo quyết định người dùng: HEAD không xác minh duration/dimensions/codec hoặc việc bỏ metadata; single checksum-signed, multipart không còn full-file worker SHA verification đường client. Presigned URLs còn TTL có thể overwrite sau complete; không bổ sung version pinning/object immutability ngoài scope. Quota dùng size thật, duration khai báo kiểm gói. Xem tài liệu contract để biết chi tiết.
