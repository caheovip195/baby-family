## Xác thực và vận hành

Hai biến môi trường bắt buộc khi phục vụ admin: `ADMIN_CMS_TOKEN_SECRET` và `ADMIN_CMS_TOTP_ENCRYPTION_KEY`, mỗi biến chứa base64 của đúng 32 byte ngẫu nhiên độc lập. Secret JWT khác app; issuer `baby-family-admin`, audience `baby-family-admin-cms`, HS256. Không dùng `AccessTokenGuard`. Session 15 phút, lưu SHA-256 token trong cột `refreshTokenHash`, không phát refresh token. Mỗi request kiểm phiên còn hạn/chưa thu hồi/admin ACTIVE/chưa xóa và đọc roles mới nhất từ DB.

Mật khẩu scrypt có salt ngẫu nhiên (deps không có argon2), TOTP SHA1 6 chữ số/30 giây ±1 bước, secret AES-256-GCM. Transaction/advisory lock chống dùng lại bước TOTP kể cả sau logout. Chính sách kỹ thuật v1 tập trung tại `src/config/admin-cms-auth-policy.ts`: 5 lượt/tài khoản và 20 lượt/client trong 15 phút, đếm cả lượt thành công; reservation + audit PostgreSQL, lock còn hiệu lực qua restart/replica. Client key lấy `request.ip`/socket; khi có proxy cần cấu hình trust proxy chính xác tại hạ tầng. Không lưu email/IP thô trong rate audit.

Tạo admin chủ động: đặt `DATABASE_URL`, `ADMIN_CMS_TOTP_ENCRYPTION_KEY`, `ADMIN_CREATE_EMAIL`, `ADMIN_CREATE_PASSWORD` (16–1024 ký tự), `ADMIN_CREATE_TOTP_SECRET` (base32, provision vào authenticator qua kênh bảo mật), `ADMIN_CREATE_ROLES` (phân cách dấu phẩy; mặc định SUPER_ADMIN), rồi chạy `npm run admin:create`. Không mật khẩu mặc định, không seed/start tự tạo admin; không in password/TOTP/token. Command chỉ in ID khi thành công, lỗi in thông báo chung. Không đưa secrets thật vào shell history/tài liệu.

Role được hỗ trợ: SUPPORT, MODERATOR, CONTENT, BILLING_OPS, OPS, ADMIN, SUPER_ADMIN. ADMIN/SUPER_ADMIN có quyền vượt role trong guard; vẫn qua case, reason và audit. SUPPORT đọc metadata case, xử lý ticket; MODERATOR xem nội dung được báo cáo/ẩn/đổi trạng thái; OPS/BILLING_OPS khoá license; CONTENT/BILLING_OPS đọc catalog.

## HTTP contract

Tất cả response thành công bên dưới nằm trong `{"data": <payload>}` qua interceptor hiện có, ngoại trừ 204 không body. Date là ISO 8601 UTC, UUID là string. DTO không nhận thuộc tính thừa; lỗi validation HTTP 400 `VALIDATION_ERROR`, UUID sai 400 `BAD_REQUEST`. Các endpoint bảo vệ dùng `Authorization: Bearer <admin accessToken>`.

### Auth

`POST /admin/v1/auth/login`, request:

```json
{
  "email": "operator@example.invalid",
  "password": "<password>",
  "totp": "123456"
}
```

HTTP 200 payload:

```json
{
  "accessToken": "<admin JWT>",
  "tokenType": "Bearer",
  "expiresAt": "2026-10-21T04:00:00.000Z",
  "issuer": "baby-family-admin",
  "audience": "baby-family-admin-cms",
  "admin": { "id": "<uuid>", "roles": ["MODERATOR"] }
}
```

`POST /admin/v1/auth/logout`, không body, HTTP 204. Thu hồi session hiện tại.

### Kiểm duyệt

`GET /admin/v1/moderation/cases?status=OPEN&offset=0&limit=25` → 200 `{items:[<case>],total:<number>}`. status optional OPEN/IN_REVIEW/RESOLVED/ESCALATED; limit 1–100, mặc định 25; offset >=0.

Case chính xác:

```json
{
  "id": "<uuid>",
  "targetType": "MEMORY",
  "targetId": "<uuid>",
  "priority": 1,
  "status": "OPEN",
  "assigneeAdminId": null,
  "slaDueAt": "<ISO>",
  "resolvedAt": null,
  "createdAt": "<ISO>",
  "updatedAt": "<ISO>",
  "deletedAt": null
}
```

`GET /admin/v1/moderation/cases/:id` → 200 case trên + `reports` và `actions`:

```json
{
  "reports": [
    {
      "id": "<uuid>",
      "reason": "<report enum>",
      "detail": "<report detail or null>",
      "severity": 1,
      "status": "OPEN",
      "createdAt": "<ISO>"
    }
  ],
  "actions": [
    {
      "id": "<uuid>",
      "adminId": "<uuid>",
      "action": "VIEW_CONTENT",
      "createdAt": "<ISO>"
    }
  ]
}
```

Hai mảng là thuộc tính thêm vào case, không response riêng. Metadata/list không lấy body nội dung bị báo cáo; detail có báo cáo do user gửi và lịch sử case. Ghi chú reasonNote của moderator không nằm trong response (ngăn nội dung dán vào ghi chú đi tới SUPPORT/OPS), chỉ lưu tại case action được bảo vệ.

`POST /admin/v1/moderation/cases/:id/content`, request `{"reason":"Review report"}` → 201:

```json
{
  "caseId": "<uuid>",
  "targetType": "MEMORY",
  "targetId": "<uuid>",
  "content": {
    "id": "<uuid>",
    "title": null,
    "body": "<reported body or null>",
    "status": "PUBLISHED"
  }
}
```

COMMENT content không có thuộc tính title. Chỉ nội dung MEMORY/COMMENT có report active khớp target/family, FAMILY/PARENTS, không deleted, không AUTHOR_ONLY/Papa&Mama, không thư còn khóa. Có audit và action VIEW_CONTENT trước khi trả. Không cấp URL media.

`PATCH /admin/v1/moderation/cases/:id/status`, request `{"status":"IN_REVIEW","reason":"Review report"}` → 200 case đầy đủ reports/actions. Nhận IN_REVIEW/RESOLVED/ESCALATED; RESOLVED không mở lại.

`POST /admin/v1/moderation/cases/:id/actions`, request `{"action":"HIDE","reason":"Safety report verified"}` → 201 case đầy đủ reports/actions. MEMORY chuyển ARCHIVED/archivedAt + tăng version; COMMENT chuyển HIDDEN, trừ commentCount đúng lần đầu, khóa cùng memory row với writer thường. Report chuyển ACTION_TAKEN; có ModerationAction + AdminAuditEvent trong cùng transaction. Ẩn lặp không trừ count lần hai; case RESOLVED không nhận HIDE.

### License

`POST /admin/v1/families/:id/license/block`, request `{"reason":"Safety case reviewed","reasonCode":"SAFETY"}` → 201:

```json
{ "familyId": "<uuid>", "blockedAt": "<ISO>", "blockReasonCode": "SAFETY" }
```

`POST /admin/v1/families/:id/license/unblock`, request `{"reason":"Safety case resolved","reasonCode":"CASE_RESOLVED"}` → 201 `{"familyId":"<uuid>","blockedAt":null,"blockReasonCode":null}`.

Reason được trim, bắt buộc 1–1000 ký tự; reasonCode block/unblock là `^[A-Z][A-Z0-9_]{0,79}$`. Audit entity là FAMILY_LICENSE, entityId là license ID, reasonCode là mã được gửi; redactedChanges có familyId, previousBlocked, blocked, reasonProvided. Không copy free text reason vào audit. Không ghi đè grant/plan hay cấp gói; query app hiện có đọc blockedAt/blockReasonCode mỗi request. `GET /api/v1/families/:id` sau block trả 403 LICENSE_BLOCKED; unblock phục hồi quyền theo entitlement còn hiệu lực. Luồng tải/xuất được giữ theo allowlist hiện có, không chặn mọi đường metadata/download.

### CSKH

`GET /admin/v1/support/tickets?offset=0&limit=50&status=OPEN` → 200 `{items:[<metadata>],nextOffset:null|number}`; limit 1–50, mặc định 50. Metadata không subject/body:

```json
{
  "id": "<uuid>",
  "requesterUserId": "<uuid or null>",
  "familyId": "<uuid or null>",
  "category": "MEDIA",
  "status": "OPEN",
  "assignedAdminId": null,
  "createdAt": "<ISO>",
  "updatedAt": "<ISO>",
  "closedAt": null
}
```

`GET /admin/v1/support/tickets/:id?reasonCode=CASE_REVIEW` → 200:

```json
{
  "id": "<uuid>",
  "code": "HT-261021-<UPPERCASE_UUID>",
  "status": "OPEN",
  "createdAt": "<ISO>",
  "category": "MEDIA",
  "categoryVersion": 1,
  "subject": "<decrypted subject>",
  "body": "<decrypted body>",
  "familyId": "<uuid or null>",
  "attachmentAssetIds": [],
  "messages": [
    {
      "id": "<uuid>",
      "sender": "SUPPORT",
      "body": "<decrypted body>",
      "createdAt": "<ISO>"
    }

```

Reuse `ISupportHelpdeskService.detail` hiện có sau audited lookup requester từ DB; client không chọn principal. Lỗi envelope/key fail closed. Chỉ các asset ID đã thuộc ticket, không presign/tải asset mới.

`POST /admin/v1/support/tickets/:id/messages`, request `{"body":"Support reply","reasonCode":"CASE_REPLY"}` → 201 `{"id":"<uuid>","sender":"SUPPORT","createdAt":"<ISO>"}`. Body trim 1–10000 ký tự, lưu AES-GCM với AAD tương thích app. Ticket chuyển WAITING_USER, assignedAdminId hiện tại. Reply ticket RESOLVED/CLOSED trả 409. User đọc reply qua API cũ `GET /api/v1/support/tickets/:id`, sender SUPPORT.

`PATCH /admin/v1/support/tickets/:id/status`, request `{"status":"RESOLVED","reasonCode":"CASE_RESOLVED"}` → 200 metadata. Nhận OPEN/IN_PROGRESS/WAITING_USER/RESOLVED/CLOSED; closedAt đặt cho hai trạng thái cuối và xóa khi mở lại. reasonCode CSKH `^[A-Z][A-Z0-9_]{2,79}$`, bắt buộc ở đọc nội dung/reply/đổi trạng thái.

### Catalog

`GET /admin/v1/catalog/:kind?offset=0&limit=50` → 200:

```json
{
  "kind": "missions",
  "items": [],
  "nextOffset": null,
  "mutationSupported": false,
  "mutationPolicy": "IMMUTABLE_PUBLISHED_VERSIONS"
}
```

kind: missions, milestones, notification-templates, plan-versions, trial-policies. Projection từng item chính xác (nullable theo schema, JSON i18n/quotas/features giữ nguyên):

- missions: id,code,stage,minAgeDays,maxAgeDays,minPregWeek,maxPregWeek,category,suggestedScope,roleFit,hearts,durationMin,multiChildOk,requestable,titleI18n,descI18n,memoryPromptI18n,tags,weight,rolloutPct,status,version.
- milestones: code,category,icon,titleI18n,promptI18n,isTraditional,dateRule,remindDaysBefore,sortOrder,status.
- notification-templates: code,locale,title,body,sensitive,hiddenTitle,hiddenBody,category,priority,enabled.
- plan-versions: id,planId,version,quotas,entitlementRank,features,availableFrom,retiredAt,plan:{id,code,displayNameI18n,displayOrder,purchaseEnabled,active}.
- trial-policies: id,code,version,planVersionId,durationSeconds,reminderOffsetsSeconds,active,publishedAt,retiredAt. durationSeconds (bigint) là chuỗi thập phân, các Date là ISO/null.

Catalog chỉ đọc. Notification PK(code,locale), milestone không version; mission code unique dù có version. Không có API toggle/publish bảo đảm bất biến trên toàn bộ catalog hiện tại; không sửa bản publish hoặc tạo overlay không được runtime sử dụng. Trial/plan cũng giữ read-only ở task này. Bổ sung workflow version/publish/toggle là phần còn lại cần thiết kế schema + consumer đồng bộ nếu triển khai tiếp.

## Mã lỗi

| HTTP | Code                                                         | Điều kiện                                                                     |
| ---- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| 400  | VALIDATION_ERROR / BAD_REQUEST                               | DTO/param sai, thiếu field                                                    |
| 401  | ADMIN_CREDENTIALS_INVALID                                    | Password/TOTP sai hoặc replay                                                 |
| 401  | ADMIN_UNAUTHORIZED                                           | Thiếu/sai/expired/revoked JWT, issuer/audience khác, admin inactive/deleted   |
| 403  | ADMIN_FORBIDDEN                                              | Thiếu role, có audit denied                                                   |
| 429  | ADMIN_LOGIN_LOCKED                                           | Vượt reservation window account/client                                        |
| 503  | ADMIN_AUTH_UNAVAILABLE                                       | Thiếu key admin hợp lệ                                                        |
| 404  | ADMIN_CASE_NOT_FOUND                                         | Case không tồn tại/đã xóa                                                     |
| 404  | ADMIN_REPORTED_CONTENT_UNAVAILABLE                           | Không report khớp, target private/sealed/deleted/unsupported                  |
| 409  | ADMIN_CASE_STATE_INVALID                                     | Mở lại/HIDE case RESOLVED                                                     |
| 422  | ADMIN_HIDE_UNSUPPORTED                                       | HIDE target ngoài MEMORY/COMMENT                                              |
| 404  | ADMIN_LICENSE_NOT_FOUND                                      | Không license active/family bị xóa                                            |
| 422  | ADMIN_REASON_REQUIRED / ADMIN_ACTION_INVALID                 | Service trực tiếp nhận reason/action sai; HTTP DTO thường chặn trước bằng 400 |
| 404  | NOT_FOUND                                                    | Ticket không tồn tại/đã xóa                                                   |
| 409  | SUPPORT_TICKET_CLOSED                                        | Reply vào RESOLVED/CLOSED                                                     |
| 503  | SUPPORT_CONTENT_UNAVAILABLE / SUPPORT_ENCRYPTION_UNAVAILABLE | Envelope không hợp lệ/requester null hoặc key thiếu                           |
| 404  | ADMIN_CATALOG_NOT_FOUND                                      | Kind catalog không hỗ trợ                                                     |
| 403  | LICENSE_BLOCKED                                              | API app read/write thuộc phạm vi chặn khi license blocked                     |

Error envelope dùng filter hiện có: `{"error":{"code":"...","message":"<localized>","details":["<optional validation details>"]},"path":"...","timestamp":"<ISO>"}`; requestId chỉ xuất hiện khi request có ID. Không thay catalog bản dịch lỗi trong task này; code mới dùng fallback bản địa hoá theo HTTP hiện có.

## Còn lại và giới hạn

- Tích hợp DI/controllers/global prefix theo các dòng trên và cấu hình hai secret; chưa phục vụ route trong AppModule thực tế theo giới hạn task.
- Chưa tạo admin thật, chưa chạy command tạo thành công (chỉ chạy thiếu input để kiểm tra từ chối). Chưa triển khai VPN/IP allowlist/process admin riêng/DB role bf_admin_api; hạ tầng phải bảo đảm không SELECT schema us theo thiết kế. Code admin mới không truy vấn us.
- Catalog read-only, chưa toggle/publish phiên bản; cần workflow version hoá thực sự nếu mở quyền ghi.
- Nội dung kiểm duyệt hiện trả text MEMORY/COMMENT đủ điều kiện, không presign/watermark media và không xử lý nội dung riêng tư/target khác; các target không hỗ trợ bị từ chối.
- Audit/attempt dùng bảng có sẵn; query đếm rate audit có thể cần index theo tải thực tế. Không có đo tải/analytics production, không khẳng định cải thiện số liệu. Tác động sản phẩm là vận hành có quyền/audit, giữ privacy theo case.
- 13 integration test không thay thế full regression/production deployment. Không chạy suite của phiên B, không sửa logs/checklist/api docs.
