## 1. Ảnh tháng MEM-20/21

Nguồn dữ liệu hiện có: monthly_photos chứa month_index, memory_id, asset_id, audit/soft-delete và unique active (child_id, month_index). Không thêm month_index vào memories.

Hợp đồng áp dụng sau khi đăng ký controller, prefix /api/v1:

- POST /children/:id/monthly-photos — 201.
- PUT /children/:id/monthly-photos/:monthIndex — 200.
- GET /children/:id/monthly-photos — 200.

POST request:

```json
{ "monthIndex": 2, "memoryId": "<uuid>", "assetId": "<uuid>" }
```

PUT request:

```json
{ "memoryId": "<uuid>", "assetId": "<uuid>" }
```

POST/PUT response:

```json
{
  "data": {
    "monthIndex": 2,
    "memoryId": "<uuid>",
    "url": "<signed URL hoặc null>",
    "occurredAt": "2025-03-21T10:00:00.000Z"
  }
}
```

GET response:

```json
{
  "data": [
    {
      "monthIndex": 2,
      "memoryId": "<uuid>",
      "url": "<signed URL hoặc null>",
      "occurredAt": "2025-03-21T10:00:00.000Z"
    }
  ]
}
```

Chọn từ ký ức đã xuất bản, đúng một bé, kind MOMENT hoặc MONTHLY_PHOTO, có IMAGE READY gắn vào ký ức. Luồng capture: upload/tạo ký ức ảnh bằng API hiện có rồi POST/PUT designation theo body trên; endpoint B không nhận binary hoặc tự tạo memory từ asset trần. Đặt ảnh chính đổi kind ký ức được chọn sang MONTHLY_PHOTO. Thay ảnh khác đổi kind ảnh cũ sang MOMENT, giữ nội dung/media/trạng thái xuất bản; không xoá ký ức cũ. PUT lặp không tạo thêm row. Khóa child và target memory trong transaction; version recheck chặn stale selection. Đây là lựa chọn theo yêu cầu mới và BR-072 ở đặc tả nghiệp vụ, dù đoạn kỹ thuật §19.5 có câu “ký ức cũ không bị đổi”.

Tháng 0..240 theo constraint hiện có, tính từ occurredLocalDate; chặn trước ngày sinh, sau hiện tại hoặc sai tháng. Có clamp cuối tháng (31/01→28/02, năm nhuận) và đếm tháng âm nhuận khi monthlyPhotoLunar bật. GET bỏ designation đã sai bé/ngày sau sửa ký ức. Collage do app ghép; không thêm API export/collage, nhắc ảnh tháng, sticker hoặc job mới.

ACL: chỉ Parent được đặt/thay, Circle chỉ xem bé được grant hiện tại và ký ức FAMILY; private của bạn đời, report-hide, block, soft-deleted, liên kết/media không active đều bị lọc. Service gọi access interface, repository chứa toàn bộ Prisma, URL qua MEDIA_SERVICE.signViewUrls theo batch.

Mã lỗi riêng/được dùng:

| HTTP    | code                                                                                              | Khi nào                                                                                                               |
| ------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 400     | BAD_REQUEST / VALIDATION_ERROR                                                                    | UUID/body/path không hợp lệ                                                                                           |
| 401     | UNAUTHORIZED hoặc mã auth hiện có                                                                 | Token/session không hợp lệ                                                                                            |
| 404     | NOT_FOUND                                                                                         | Bé không tồn tại/không được grant; memory không tồn tại hoặc private của bạn đời; Circle gọi mutation không là Parent |
| 422     | MONTH_INDEX_INVALID                                                                               | Path monthIndex ngoài 0..240                                                                                          |
| 422     | MONTH_INDEX_MISMATCH                                                                              | Tháng không khớp ngày ký ức hoặc thiếu ngày sinh                                                                      |
| 422     | MONTHLY_PHOTO_INVALID                                                                             | Sai kind/status/subject/asset không READY IMAGE hoặc không thuộc ký ức                                                |
| 412     | VERSION_CONFLICT                                                                                  | Ký ức thay đổi trước transaction đặt ảnh                                                                              |
| 402/403 | SUBSCRIPTION_REQUIRED / FAMILY_NOT_ACTIVE / LICENSE_BLOCKED / CIRCLE_PAUSED và lỗi access hiện có | Access service giữ nguyên quy tắc                                                                                     |

## 3. Accept-Language và nội dung hệ thống

Ưu tiên header được hỗ trợ (vi/en, có q và regional tags) → users.locale của actor đã xác minh → vi. Đây là thứ tự theo yêu cầu hiện tại, ưu tiên hơn thứ tự users.locale trước header trong tài liệu kỹ thuật cũ §11.8.

RequestLocaleInterceptor tạo AsyncLocalStorage context; HttpExceptionFilter resolve locale cả khi guard lỗi trước interceptor. Dependency mới của filter optional, thiếu binding vẫn hỗ trợ header/vi. Catalog lỗi có version 1, key theo code; giữ nguyên code/envelope/details. Các code chưa có bản dịch riêng dùng thông điệp an toàn theo HTTP status. Không tự dịch nội dung người dùng. Validation details giữ nguyên chuỗi validator, chỉ error.message dịch.

Ví dụ lỗi HTTP 422:

```json
{
  "error": {
    "code": "MONTH_INDEX_MISMATCH",
    "message": "Tháng tuổi không khớp với ngày chụp ảnh."
  },
  "path": "/api/v1/children/<id>/monthly-photos/1",
  "timestamp": "<ISO timestamp>"
}
```

Với Accept-Language: en, cùng code và message “The month index does not match the photo date.” requestId có thêm khi middleware/logger cấp id.

GET /api/v1/notifications?tab=FAMILY&limit=20 giữ contract cũ, nếu renderer đã đăng ký mỗi item thêm title/body/locale:

```json
{
  "data": {
    "items": [
      {
        "id": "<uuid>",
        "tab": "FAMILY",
        "category": "MEMORY",
        "templateCode": "MEMORY_PUBLISHED",
        "title": "New memory",
        "body": "<rendered template>",
        "locale": "en",
        "params": {},
        "createdAt": "<ISO timestamp>",
        "readAt": null,
        "deepLink": "<existing link>"
      }
    ],
    "nextCursor": null
  }
}
```

Đây là ví dụ shape; title/body phụ thuộc template đã seed, không seed nội dung trong task. Chọn template request locale → en → vi; disabled/deleted không dùng. Không có template: title/body=null, locale=request locale. Sensitive dùng hiddenTitle/hiddenBody hoặc system catalog version 1, không interpolate dữ liệu riêng. Không đổi notification.locale đã lưu; worker push/email vẫn dùng locale người nhận. Renderer dependency optional để module test tập trung cũ tiếp tục chạy.
